# External Integrations

**Analysis Date:** 2026-01-28

## APIs & External Services

**Email Delivery:**
- Resend - Sends bycatch alert emails to fleet members
  - SDK/Client: TypeScript/Fetch API in Edge Function
  - Auth: `RESEND_API_KEY` environment variable
  - Usage: Called from Supabase Edge Function `send-bycatch-alert`
  - Rate limit: 100 emails/day (free tier warning at 90+)
  - Endpoint: `https://api.resend.com/emails` (POST)
  - Free tier: 100 emails/day

**Fonts & UI Resources:**
- Google Fonts - DM Sans font family for UI
  - Source: `https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;600;700`
  - Usage: Embedded in login page and sidebar styling
  - Purpose: Typography for professional maritime-themed interface

## Data Storage

**Databases:**
- PostgreSQL 17 (via Supabase)
  - Connection: Via Supabase client using `SUPABASE_URL` and `SUPABASE_KEY`
  - Client: Supabase Python SDK (v2.0.0+)
  - Local dev: Supabase CLI with local PostgreSQL instance
  - Features: Row Level Security (RLS) policies, soft deletes, multi-tenancy via org_id
  - Key tables: `organizations`, `coop_members`, `quota_transfers`, `harvests`, `bycatch_alerts`, `bycatch_hauls`, `vessel_contacts`, `user_profiles`

**File Storage:**
- Supabase Storage - For file uploads
  - Connection: Via Supabase client
  - Purpose: Roster uploads, harvest reports (Excel files)
  - File size limit: 50MiB
  - Not explicitly configured for public buckets

**Caching:**
- Streamlit built-in caching - `@st.cache_data` and `@st.cache_resource`
  - TTL: 60-300 seconds for various data fetches
  - Examples: `_fetch_alerts()` (60s), `_fetch_psc_species()` (300s), `get_filter_options()` (300s)

## Authentication & Identity

**Auth Provider:**
- Supabase Auth (built-in)
  - Implementation: JWT-based email/password authentication
  - JWT expiry: 3600 seconds (1 hour)
  - Refresh tokens: Enabled with rotation (10 second reuse interval)
  - Signup: Enabled (can be disabled per project)
  - Email confirmation: Disabled locally
  - Multi-factor auth: Not enabled (MFA config available but disabled)
  - User profiles: Extended via `user_profiles` table with role, processor_code, org_id, llp

**Session Management:**
- JWT tokens stored in Streamlit session state
  - `access_token` - For API requests
  - `refresh_token` - For token refresh when expired
  - Automatic refresh on expiry via `check_and_refresh_session()`
  - Session timeout: No forced logout configured

## Environment Configuration

**Required env vars:**
- `SUPABASE_URL` - Supabase project URL (https://xxxxx.supabase.co)
- `SUPABASE_KEY` - Anon key for frontend (public)
- `SUPABASE_SERVICE_ROLE_KEY` - Service role key for tests (bypasses RLS, secrets)

## Webhooks & Callbacks

**Incoming:**
- Supabase Edge Function: `send-bycatch-alert` (POST)
  - Invoked from Python when manager clicks "Share to Fleet"
  - Endpoint: `https://{project-ref}.supabase.co/functions/v1/send-bycatch-alert`
  - Auth: JWT Bearer token (from `access_token`)
  - Payload: `{ alert_id: string }`
  - Returns: `{ success: boolean, sent_count: number, haul_count: number, resend_id?: string, error?: string }`

**Outgoing:**
- Resend Email API - Sends emails to vessel contacts
  - Called from Edge Function
  - Recipients: All vessel contacts in org (from `vessel_contacts` table)
  - Email format: HTML + plaintext (both generated by Edge Function)

## Rate Limiting

**Supabase Auth:**
- Email sent: 2 per hour
- SMS sent: 30 per hour
- Token refresh: 150 per 5 minutes per IP
- Sign in/up: 30 per 5 minutes per IP (excludes anonymous)
- OTP/Magic link: 30 per 5 minutes per IP

**Resend (Email):**
- Free tier: 100 emails per day
- Warning logged if recipients > 90 (approaching daily limit)

**PostgREST API:**
- Max rows returned: 1000 (configured in api.max_rows)
