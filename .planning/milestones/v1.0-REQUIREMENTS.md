# Requirements: Fishermen First - Metrics Layer

**Defined:** 2026-01-28
**Core Value:** Accurate quota tracking — the `quota_remaining` calculation must be correct and consistent everywhere

## v1 Requirements

Requirements for v1.0 milestone. Each maps to roadmap phases.

### Derived Metrics

- [x] **METR-01**: `quota_metrics` view includes `remaining_pct` calculated from remaining_lbs/allocation_lbs
- [x] **METR-02**: `quota_metrics` view includes `risk_level` (critical <10%, warning <50%, healthy >=50%)
- [x] **METR-03**: Division by zero handled gracefully (allocation_lbs = 0)
- [x] **METR-04**: SQL COMMENT documents `quota_remaining` view definition and assumptions

### Sanity Checks

- [x] **CHEK-01**: Check query detects negative allocations
- [x] **CHEK-02**: Check query detects over-transferred quota (remaining < 0)
- [x] **CHEK-03**: Check query detects future-year data
- [x] **CHEK-04**: Check query detects invalid species codes
- [x] **CHEK-05**: Checks runnable via single SQL file (checks.sql)

### Serving Views

- [x] **SERV-01**: `kpi_daily_by_species` view aggregates harvests by day/species
- [x] **SERV-02**: `kpi_coop_summary` view aggregates quota_metrics by coop/species
- [x] **SERV-03**: Coop summary includes critical_count and warning_count

### Reconciliation

- [x] **RECO-01**: `reconciliation_variance` view compares quota_remaining vs eFish account_balances
- [x] **RECO-02**: Variance view includes variance_lbs (internal - external)
- [x] **RECO-03**: Variance view flags rows needing investigation (>100 lbs variance)

### Dashboard Integration

- [x] **DASH-01**: Dashboard uses `quota_metrics` view instead of calculating % in Python
- [x] **DASH-02**: Dashboard risk level logic matches SQL view risk_level
- [x] **DASH-03**: Existing dashboard functionality unchanged (visual regression)

## Future Requirements

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| DuckDB integration | PostgreSQL handles this workload fine |
| BI tool changes | Views are the contract; Streamlit remains viewer |
| New dashboard features | Metrics layer hardening only |
| Real-time alerts | Separate feature, not metrics layer |
