   - SELECT from allocations table WHERE allocation_lbs < 0
   - Include columns: check_id='CHEK-01', issue description, org_id, llp, species_code, year, allocation_lbs

   - SELECT from quota_metrics view WHERE remaining_lbs < 0
   - Include columns: check_id='CHEK-02', issue description, org_id, llp, species_code, year, allocation_lbs, transfers_in, transfers_out, harvested, remaining_lbs
   - ORDER BY remaining_lbs ASC (most negative first), then year DESC, llp

4. CHEK-03: Future Year Data
   - Use CTE to capture current year: EXTRACT(YEAR FROM CURRENT_DATE)::INTEGER
   - Check three tables: allocations, transfers, harvests
   - For transfers and harvests: filter WHERE NOT is_deleted (soft-delete pattern)
   - UNION ALL results from all three tables
   - Include columns: check_id='CHEK-03', issue description, table_name, org_id, llp, species_code, year, current_year
   - ORDER BY table_name, year DESC, llp

5. CHEK-04: Invalid Species Codes
   - Use NOT EXISTS to check species_code against species table
   - Check three tables: allocations, transfers, harvests
   - For transfers and harvests: filter WHERE NOT is_deleted
   - Use DISTINCT with COUNT(*) to show affected_rows per species_code
   - Include columns: check_id='CHEK-04', issue description, table_name, species_code, affected_rows
   - ORDER BY table_name, species_code

6. Consolidated Summary Report (commented out):
   - UNION ALL combining all four checks
   - Simplified columns for quick scan
   - Documented as optional for full-scan reporting
