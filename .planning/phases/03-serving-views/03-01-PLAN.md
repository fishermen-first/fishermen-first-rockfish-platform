   ```sql
   CREATE OR REPLACE VIEW kpi_daily_by_species
   WITH (security_invoker = true)
   AS
   SELECT
       org_id,
       DATE_TRUNC('day', landing_date) AS landing_day,
       species_code,
       SUM(pounds) AS total_harvested_lbs,
       COUNT(*) AS harvest_count
   FROM harvests
   WHERE NOT is_deleted
   GROUP BY org_id, DATE_TRUNC('day', landing_date), species_code
   ORDER BY landing_day DESC, species_code;
   ```

3. COMMENT ON VIEW documenting:

   - Filter applied (non-deleted harvests only)
   - RLS compatibility (security_invoker = true)
   - Use cases (dashboard time-series charts, daily trends)

IMPORTANT:
- Use `landing_date` column (NOT `harvest_date` - that column doesn't exist in harvests table)
- Use `NOT is_deleted` filter (matches quota_remaining view pattern)
- Include org_id in GROUP BY (multi-tenant requirement)
- Use DATE_TRUNC('day', landing_date) for proper date grouping
